# NJ ELEC — Site web professionnel

Site vitrine moderne pour **NJ ELEC**, entreprise d'électricité générale basée à **Bonneuil-en-France (95)**.

## Fonctionnalités

- Design moderne et responsive (mobile-first)
- Sections : Accueil, Services, À propos, Réalisations, Contact
- Photos libres de droits (Unsplash) — **non contractuelles**
- Formulaire de contact démo
- Menu mobile

## Déploiement GitHub Pages

1. Allez dans **Settings** > **Pages**
2. Source : **Deploy from a branch**
3. Branch : `main` / folder `/ (root)`
4. Enregistrez

`https://navsingh0786-cyber.github.io/nj-elec-website/`
